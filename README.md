# PapaBin — локальная копия со светлой темой

Снимок главной страницы https://papabin.com/ + светлая тема с переключателем.

## Как открыть в VS Code
1. `File → Open Folder…` → выбрать папку `papabin-site`.
2. Установить расширение **Live Server** (Extensions → поиск «Live Server», автор Ritwick Dey).
3. Правый клик по `index.html` → **Open with Live Server**.
   (Можно и просто открыть `index.html` в браузере.)

Нужен интернет: Tailwind, шрифты, картинки и видео грузятся с CDN и с papabin.com.

## Файлы
| Файл | Что это |
|---|---|
| `index.html` | разметка сайта (пререндер с papabin.com) |
| `assets/app.css`, `assets/home.css` | оригинальные стили сайта, без изменений |
| `assets/theme-light.css` | **светлая тема** — все переопределения под `html.light` |
| `assets/main.js` | переключатель темы + прелоадер, анимации, счётчики, FAQ, мобильное меню |

## Как работает тема
- Кнопка солнце/луна в шапке (десктоп и мобайл) переключает класс `light` на `<html>`.
- Выбор сохраняется в `localStorage` (`papabin-theme`). Если не выбран — берётся системная тема.
- Маленький скрипт в `<head>` ставит класс до отрисовки, поэтому нет «вспышки» тёмной темы.
- Цвета светлой темы — CSS-переменные в начале `theme-light.css` (`--lt-bg`, `--lt-card`, `--lt-fg`, `--lt-money-text`…).
- Зелёный для текста затемнён до `#46732F` (контраст 5.2:1, WCAG AA). Зелёные плашки/кнопки остались брендовыми `#85BB65`.

## Чтобы перенести в настоящий проект (Vue + Vite)
1. Скопировать `assets/theme-light.css` и подключить после основных стилей.
2. Ранний скрипт из `<head>` `index.html` перенести в `index.html` проекта.
3. Кнопку переключателя оформить компонентом в навбаре (логика — функция `applyTheme` в `main.js`).

Не перенесено: Google Analytics (убран, чтобы не слать локальные визиты), страницы блога и юр. страницы ведут на живой сайт.
